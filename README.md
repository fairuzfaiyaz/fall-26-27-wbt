## Mission

To educate students in a student-centric dynamic learning environment, provide advanced facilities for innovative research and development to meet modern computing challenges, and motivate lifelong learning.

---

## Course Description

By this course, students are expected to:

- Appreciate the increasing importance of web technologies and their impact on IT.
- Understand strategic web development and apply frameworks for internet-based solutions.
- Compare fundamental web technologies and evaluate real business benefit.
- Explore new technologies and emerging issues in web development.
- Apply web development approaches in organizational analysis.
- Describe information system development processes, web engineering, and process reengineering.
- Analyze skills required for web development professionals.
- Develop real-life and society-targeted web applications.

## AI Policy (Project Work)

Use of AI tools is strongly discouraged.  
If any AI tool is used, prior consent from the course teacher is required, and students must clearly state:

1. Which AI tool was used.
2. Which exact parts of the work used AI.

Students must be able to explain all submitted work. Any AI-generated content that cannot be explained may be marked as **Missing/Incorrect (0)**.
